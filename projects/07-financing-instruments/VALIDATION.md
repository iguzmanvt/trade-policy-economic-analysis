# Validation and limits

The model is ready for use as an **illustrative analytical sample within the stated scope**. All inputs are synthetic. Validation does not establish country affordability, climate-loss attribution, FRLD eligibility, institutional approval or equivalence with an official grant-element calculator.

## What was checked

The standard-library test suite contains 11 substantive tests covering equal initial funding, no repayment for a pure grant, full principal reconciliation, the first-principal-payment convention, a closed-form check of total nominal interest, a pricing identity when the reference loan rate equals the discount rate, a separate explicit discounted-payment sum, proportionality of the mixed package, the timing of exchange-rate and envelope shocks, discount sensitivity, and monthly cash-gap calculations. Invalid-input cases cover duplicate IDs, NaN, invalid principal holidays, a zero denominator and unequal initial funding. A failed input validation leaves previous result files unchanged.

The tests run both normally and with Python optimization (`-O`). Critical runtime validation uses explicit exceptions rather than `assert`, so optimization does not remove it. File paths resolve relative to the script rather than the current working directory.

The independently specified checks yield USD 13 million of nominal interest for the concessional loan and a USD 100 million present value for the reference loan at its 5% coupon/discount rate. The concessional loan's independently calculated present value is USD 63.3745795835 million. The peak monthly gap for funding received in month 3 is USD 60 million; summing repeated monthly gaps would be incorrect.

The static figure was generated from the result CSVs with Matplotlib and visually inspected for visible marks, accurate labels, readable text and clipping. Its scales start at zero for debt service and fiscal ratios. The plotted annual horizon is relative years, not calendar dates. All fiscal-sensitivity values use an assumed envelope; the figure explicitly labels its synthetic status.

## Reproduction commands

```bash
python analyze.py
python tests/test_model.py
python -O tests/test_model.py
```

The analysis writes six CSV files and a small runtime `validation.json` containing the input hash and row counts. It validates and completes the calculation before writing outputs. The test suite provides the stronger boundary and independent arithmetic checks; the runtime `PASS` alone does not mean those tests have been run. Figures use the optional `build_figure.py` command and are not regenerated by core analysis.

## Interpretation limits

1. The USD 100 million scale, interest rates, maturities, repayment holiday, exchange-rate paths, envelopes and spending path are illustrative choices. They are not observed data, predictions or FRLD terms.
2. The package PV measure is discounted contractual cash flow, not immediate liquidity, a provider's subsidy accounting or estimated welfare. Different packages do not have an equal resource cost to the provider.
3. The FX scenarios change the local-currency cost of fixed USD debt service. They do not alter the USD present-value calculation, estimate a devaluation probability or model inflation, growth and revenue feedbacks.
4. Annual debt schedules and the monthly disbursement experiment are distinct exercises. The delayed receipt is not silently inserted into the annual present-value comparison.
5. The country debt portfolio, contingent liabilities, external financing needs, political and legal context, distributional effects, fiduciary capacity and environmental/social safeguards are outside the numerical model.
6. The source record distinguishes the Governing Instrument's broad mandate from the grant-based BIM phase described in the 2026 Board report. It does not treat a possible future instrument as approved for current access.
